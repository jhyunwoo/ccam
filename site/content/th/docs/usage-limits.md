`ccam usage` แสดงว่าแต่ละบัญชีใช้ขีดจำกัดแต่ละแบบไปแล้วเท่าไร ได้แก่ ขีดจำกัดแบบ 5 ชั่วโมง ขีดจำกัดรายสัปดาห์ และขีดจำกัดรายสัปดาห์เฉพาะของแต่ละโมเดล (เช่น Fable) `ccam next --auto` เปิดบัญชีที่เหลือโควตามากที่สุด และ `--continue` จะนำการสนทนาปัจจุบันไปต่อด้วย

```console
$ ccam usage
 1 personal  just now
   5-hour   ██████████████░░░░░░  72%  resets in 1h 40m
   Weekly   ████████░░░░░░░░░░░░  41%  resets in 3d 6h
   Fable    ██████████████████░░  88%  resets in 1d 6h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
   Fable    █░░░░░░░░░░░░░░░░░░░   3%  resets in 5d 2h
 3 side      12m ago (cached)
   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
   Fable    ████████░░░░░░░░░░░░  40%  resets in 1d 9h
→ Most headroom: work   (open it with ccam next --auto)
```

แต่ละบัญชีจะมีหนึ่งบรรทัดที่บอกอายุของตัวเลข ตามด้วยแถบหนึ่งแถบต่อขีดจำกัดพร้อมเวลาที่เหลือจนถึงการรีเซ็ต ได้แก่ ช่วง 5 ชั่วโมง ช่วงรายสัปดาห์สำหรับทุกโมเดล และช่วงรายสัปดาห์เฉพาะของแต่ละโมเดล เช่น Fable แถบจะเปลี่ยนเป็นสีเหลืองที่ 80% และเป็นสีแดงที่ 100% บรรทัดสุดท้ายระบุบัญชีที่ `ccam next --auto` จะเปิด เมื่อตั้ง `auto_strategy = "expiring"` หรือ `"balance"` บรรทัดนั้นจะเป็น `→ next --auto picks <name>: <reason>` แทน

**ที่นั่ง (seat) ของ Team และ Enterprise** การเลือกบัญชีอัตโนมัติ (`ccam next`, `--fallback`, `ccam pick`, ปุ่ม `n` ในแดชบอร์ด และ [`auto_switch`](/features/next#auto-switch) เมื่อคุณเปิดใช้) จะสลับระหว่างที่นั่งต่าง ๆ ในองค์กร Claude Team หรือ Enterprise เดียวกันด้วย ซึ่งอาจละเมิดข้อกำหนดของ Anthropic โปรดอ่าน[คำถามที่พบบ่อย](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) และสอบถามองค์กรของคุณและ Anthropic ก่อนที่จะพึ่งพาการเลือกอัตโนมัติ

## ตัวเลขมาจากไหน

ccam สอบถาม endpoint การใช้งานของ Anthropic สำหรับทุกบัญชีพร้อมกัน โดยใช้การเข้าสู่ระบบของแต่ละบัญชีเอง ccam รอไม่เกิน 3 วินาทีต่อบัญชี และแสดงแต่ละบัญชีทันทีที่ได้รับคำตอบ

endpoint นี้ไม่มีเอกสารเผยแพร่สู่สาธารณะและอาจเปลี่ยนแปลงได้ เมื่อคำขอล้มเหลว ccam จะแสดงตัวเลขล่าสุดที่ทราบและระบุว่าเป็นข้อมูลจากแคช ช่วงเวลาที่รีเซ็ตไปแล้วหลังจากบันทึกตัวเลขเหล่านั้นจะแสดงเป็น 0% `ccam doctor` จะแจ้งให้คุณทราบหากรูปแบบของคำตอบเปลี่ยนไป

เมื่อ Claude Code หยุดเซสชันเพราะถึงขีดจำกัดการใช้งาน [ปลั๊กอิน ccam](/docs/install#claude-code-plugin) จะบันทึกว่าช่วงใดเต็มและจะรีเซ็ตเมื่อใด จนกว่าจะถึงเวลานั้น ช่วงนั้นจะแสดง 100% ไม่ว่าตัวเลขอื่นจะเป็นเท่าใด ดังนั้น `ccam next --auto` และ `--fallback` จะไม่เลือกบัญชีนั้นอีกเร็วเกินไป

ตัวเลขที่ดึงมาเมื่อไม่ถึง 60 วินาทีที่แล้วจะถูกนำกลับมาใช้ซ้ำ ตัวเลือก:

| ตัวเลือก | ผลลัพธ์ |
| --- | --- |
| `--watch[=seconds]` | รีเฟรชต่อเนื่อง ทุก 60 วินาทีโดยค่าเริ่มต้น |
| `--json` | ผลลัพธ์ที่เครื่องอ่านได้ |
| `-v` | แสดงแหล่งที่มาของตัวเลขของแต่ละบัญชีด้วย |
| `--no-cache` | สอบถามใหม่ทุกครั้ง |
| `--source cache` | ไม่สอบถามเลย แสดงเฉพาะตัวเลขที่บันทึกไว้ |

## การเข้าสู่ระบบที่หมดอายุ

เมื่อโทเค็นการเข้าถึงของบัญชีหมดอายุ ccam จะไม่ต่ออายุให้ เพราะการต่ออายุขณะที่เซสชัน Claude Code กำลังใช้การเข้าสู่ระบบเดียวกันอยู่ อาจทำให้เซสชันนั้นถูกออกจากระบบ บัญชีจะแสดง ``access token expired; `ccam <name>` renews it when it starts``: ให้เริ่มบัญชีนั้นหนึ่งครั้งด้วย `ccam <name>` แล้ว Claude Code จะต่ออายุให้ การเข้าสู่ระบบที่หมดอายุทั้งหมด หรือที่ Claude Code ล้างไปแล้ว จะแสดง `` login expired → `ccam login <name>` `` และต้องเข้าสู่ระบบใหม่

`ccam usage --refresh` ต่ออายุโทเค็นที่หมดอายุด้วยตัวเอง แต่เฉพาะบัญชีที่ไม่มีเซสชัน Claude Code ทำงานอยู่เท่านั้น ไม่ว่าเซสชันนั้นจะถูกเริ่มด้วยวิธีใด และจะไม่ต่ออายุการเข้าสู่ระบบที่เก็บไว้ในพวงกุญแจ (Keychain) ของ macOS หรือใน `~/.claude` ที่นำเข้ามา การต่ออายุอาจใช้เวลาถึง 30 วินาที

## การใช้งานในแถบสถานะ

```sh
ccam statusline install
```

จากนั้น Claude Code จะแสดงชื่อบัญชีและการใช้งานของบัญชีในแถบสถานะ เช่น `[work] · Opus · 5h 24% · 7d 41%` ตั้งแต่ 90% ขึ้นไป แถบสถานะจะแนะนำ `ccam next --auto --continue` ด้วย หากคุณมีคำสั่งแถบสถานะอยู่แล้ว ccam จะเก็บคำสั่งนั้นไว้และใส่ชื่อบัญชีไว้ด้านหน้า แถบสถานะยังบันทึกตัวเลขของตัวเองไว้ด้วย ซึ่ง `ccam usage` จะนำมาใช้เมื่อ endpoint ไม่ตอบกลับ

## การสลับบัญชี

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the most room
ccam next --continue  # continue this folder's conversation on the next account
```

`ccam next` จะข้ามบัญชีที่ยังไม่ได้เข้าสู่ระบบ และ `--auto` จะข้ามบัญชีที่ใช้ไปถึง 100% แล้ว (รวมถึงช่วงที่ Claude Code รายงานว่าเต็ม จนกว่าจะรีเซ็ต) และบัญชีขององค์กรอื่น เมื่อสองบัญชีใช้ประวัติการสนทนาร่วมกัน `--continue` จะเปิดการสนทนาเดียวกัน หากไม่ได้ใช้ร่วมกัน Claude Code จะคัดลอกการสนทนานั้นไปยังบัญชีใหม่ ดูที่ [การใช้ร่วมกัน](/docs/sharing) และ [การสลับไปยังบัญชีถัดไป](/features/next#continue)

เมื่อตั้ง `auto_switch = true` ที่ด้านบนสุดของ `config.toml` (Linux และ macOS ปิดไว้โดยค่าเริ่มต้น) ccam จะสลับให้เองเมื่อ Claude Code หยุดเซสชันแบบโต้ตอบเพราะถึงขีดจำกัด และมีอีกบัญชีหนึ่งประเภทเดียวกัน (ที่นั่งในองค์กรเดียวกัน หรืออีกแพ็กเกจส่วนตัวหนึ่ง) ที่ยังมีโควตาเหลือ ดู [`auto_switch`](/features/next#auto-switch) ว่าจะทำงานเมื่อใด และสิ่งใดที่จะไม่ทำเด็ดขาด

สำหรับสคริปต์และงานตามกำหนดเวลาที่รัน `claude -p` ให้ใส่ `--fallback` ไว้หน้าชื่อบัญชี เมื่อบัญชีนั้นถึงขีดจำกัด ccam จะรันคำสั่งเดิมอีกครั้งด้วยบัญชีที่เหลือโควตามากที่สุด และพิมพ์เฉพาะผลลัพธ์ของการรันที่ทำงานจนจบ:

```sh
ccam --fallback work -p "review the diff" --output-format json
```
