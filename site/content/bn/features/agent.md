Claude Code-এর নিজস্ব subagent-গুলো যে সেশন তাদের চালু করে সেই সেশনের অ্যাকাউন্ট হিসেবে চলে, তাই তারা ওই অ্যাকাউন্টের ব্যবহার খরচ করে। `ccam agent "<task>"` একই ফোল্ডারে আপনার আরেকটি অ্যাকাউন্ট হিসেবে `claude -p` দিয়ে একটি কাজ চালায় এবং Claude-এর শেষ উত্তর প্রিন্ট করে। কোনো Claude Code সেশন থেকে ডাকা হলে এটি এমন একটি subagent-এর মতো কাজ করে যা অন্য অ্যাকাউন্টের ব্যবহার খরচ করে, তাই সেশনের নিজের অ্যাকাউন্ট যেখানে ফুরিয়ে যেত তার পরেও একটি দীর্ঘ কাজ চলতে পারে।

**Team ও Enterprise সিট।** `ccam agent` নিজেই অ্যাকাউন্ট বেছে নেয়। একই Claude Team বা Enterprise প্রতিষ্ঠানের মধ্যে এটি কাজটি অন্য একটি সিটে চালায়, যা Anthropic-এর শর্তাবলি লঙ্ঘন করতে পারে। এর ওপর নির্ভর করার আগে [প্রশ্নোত্তর](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) পড়ুন এবং আপনার প্রতিষ্ঠান ও Anthropic-এর কাছ থেকে জেনে নিন।

## ব্যবহার

Claude Code এটি তার Bash টুল দিয়ে চালায়। [ccam প্লাগইন](/docs/install#claude-code-plugin) ইনস্টল করা থাকলে সহজ কথায় এটি চেয়ে নিন, যেমন "এই কাজের কিছু অংশের জন্য আমার অন্য অ্যাকাউন্টগুলো ব্যবহার করো", অথবা কথাটি আপনার CLAUDE.md-এ লিখে রাখুন। প্লাগইনের skill Claude Code-কে বলে প্রতিটি এজেন্ট ব্যাকগ্রাউন্ডে চালু করতে, এমন একটি কাজ লিখতে যা নিজে থেকেই বোঝা যায়, এবং যে এজেন্টরা ফাইল সম্পাদনা করে তাদের নিজস্ব অংশ বা নিজস্ব git worktree দিতে।

```sh
ccam agent "find why TestParse fails and fix it; reply with what you changed"
ccam agent --model opus -- "-v breaks the parser: find out why"
ccam agent --json < task.md            # the task from standard input
ccam agent --resume 7f3c9a2e-… "now add a test for it"
ccam agent --wait=1h "…"               # nobody has room: wait for a reset
ccam --dry-run agent "…"               # the account and command it would run
```

```console
$ ccam agent "summarize what internal/usage does"
ccam: agent runs as work (12% of its 5 hours used); session 7f3c9a2e-5b1d-4c2a-9e8f-1a2b3c4d5e6f
internal/usage looks up the 5-hour and weekly usage of every account …
ccam: agent finished as work; follow up with: ccam agent --resume 7f3c9a2e-5b1d-4c2a-9e8f-1a2b3c4d5e6f "…"
```

Claude-এর শেষ উত্তর স্ট্যান্ডার্ড আউটপুটে যায়; `ccam:` দিয়ে শুরু হওয়া লাইনগুলো স্ট্যান্ডার্ড এররে যায়। এর বদলে `--json` প্রিন্ট করে `{account, session_id, result, is_error, accounts}`, যেখানে `accounts` সেই সব অ্যাকাউন্টের তালিকা দেয় যেগুলো হিসেবে কাজটি চলেছে।

এক্সিট কোড: claude-এর নিজস্ব কোড (এজেন্ট শেষ হলে `0`), যে অ্যাকাউন্ট থেকে ডাকা হয়েছে সেটি ছাড়া আর কোনো অ্যাকাউন্টে জায়গা না থাকলে `75` (`EX_TEMPFAIL`), এবং অন্য ত্রুটির জন্য `1`, যেমন কোনো এজেন্ট আরেকটি এজেন্ট চালু করার চেষ্টা করলে।

## অপশন

| অপশন | কী করে | ডিফল্ট |
| --- | --- | --- |
| `--model <model>` | এজেন্টের মডেল; বাছাইয়ে ওই মডেলের সাপ্তাহিক উইন্ডোও গোনা হয় | অ্যাকাউন্টের ডিফল্ট মডেল |
| `--resume <id>` | আগের কোনো এজেন্টের কথোপকথন একটি ফলো-আপ কাজ দিয়ে চালিয়ে যায় (সেশন id থাকে তার প্রথম ও শেষ লাইনে) | বন্ধ |
| `--json` | অ্যাকাউন্ট, সেশন, উত্তর এবং যে অ্যাকাউন্টগুলো হিসেবে কাজটি চলেছে সেগুলো প্রিন্ট করে | বন্ধ |
| `--max-usage <1-100>` | এই ব্যবহারের নিচে থাকা অ্যাকাউন্টগুলোকে অগ্রাধিকার দেয় | `auto_max_usage`, অন্যথায় 100 |
| `--strategy headroom\|expiring\|balance` | [বাছাইয়ের নিয়ম](/features/next#auto) | `auto_strategy`, অন্যথায় `headroom` |
| `--cross-org` | অন্য প্রতিষ্ঠানের অ্যাকাউন্ট হিসেবেও চালায় | `cross_org`, অন্যথায় বন্ধ |
| `--wait[=<duration>]` | কোনো অ্যাকাউন্টে জায়গা না থাকলে প্রথমটি রিসেট হওয়া পর্যন্ত অপেক্ষা করে, সর্বোচ্চ এতক্ষণ | বন্ধ; একা দিলে `5h` |
| `--dry-run` | যে অ্যাকাউন্ট বেছে নিত তার জন্য কমান্ডটি প্রিন্ট করে, না চালিয়ে | বন্ধ |

## এটি কীভাবে কাজ করে

1. **যে ডাকে সে বাদ থাকে।** যে অ্যাকাউন্ট থেকে `ccam agent` ডাকা হয় (ccam যে সেশন চালু করেছে তার অ্যাকাউন্ট, নইলে এই ফোল্ডার যে অ্যাকাউন্ট চালু করে) সেটি কখনও এজেন্ট চালায় না, একই Claude অ্যাকাউন্টে লগইন করা অন্য কোনো ফোল্ডারও নয়, কারণ সেটি ওই অ্যাকাউন্টের সীমা ভাগ করে নেয়। যে অ্যাকাউন্ট থেকে এটিকে ডাকা হয়েছে, এজেন্ট সেই অ্যাকাউন্টের [প্রতিষ্ঠানের](/features/next#auto) মধ্যেই থাকে, যদি না `--cross-org` অন্য কিছু বলে।
2. **এটি `ccam pick`-এর মতো বাছাই করে।** [`ccam pick`](/features/pick) যেভাবে করে সেভাবেই ব্যবহার জিজ্ঞেস করা হয়, এবং একে অপরের ২ মিনিটের মধ্যে চালু হওয়া এজেন্টরা আলাদা অ্যাকাউন্ট পায়, যতক্ষণ যথেষ্ট অ্যাকাউন্টে জায়গা থাকে।
3. **এটি সেশনের অনুমতি নিয়েই চলে, কখনও তার বেশি নয়।** `claude -p`-এ কোনো টুলকে অনুমতি দেওয়ার জন্য কেউ থাকে না, তাই যে সেশন এজেন্টকে ডেকেছে এজেন্ট তার permission mode ও effort level পায়। টার্মিনাল থেকে চালালে Claude Code-এর ডিফল্ট mode এবং আপনার সেটিংসের permission rule প্রযোজ্য হয়। `ccam agent`-এর এমন কোনো অপশন নেই যা এর বেশি অনুমতি দেয়।
4. **ব্যবহারের সীমায় কথোপকথন এগিয়ে যায়।** এজেন্টের অ্যাকাউন্ট সীমায় পৌঁছালে ccam সীমাটি সেভাবেই নথিভুক্ত করে যেভাবে [প্লাগইনের হুক](/features/usage#the-limit-record) করত, এবং সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্ট হিসেবে একই কথোপকথন চালিয়ে যায়: Claude Code সেটি সেখানে কপি করে (`--resume <file> --fork-session`), আর প্রথম বার্তা হয় "Your usage limit was reached and ccam moved this conversation to another account. Continue the task you were working on when the limit was reached; do not repeat work that is already complete." প্রতিটি অ্যাকাউন্ট একবারই চেষ্টা করা হয়।
5. **প্রতিটি এজেন্ট-কথোপকথন নথিভুক্ত হয়** `~/.local/state/ccam/agent/<session id>.json`-এ (৩০ দিন)। `--resume <id>` সেটিকে তার ফোল্ডারে চালিয়ে যায়, যে অ্যাকাউন্ট সেটি চালিয়েছিল তাতে এখনও জায়গা থাকলে সেই অ্যাকাউন্ট হিসেবে, নইলে অন্য কোনো অ্যাকাউন্ট হিসেবে। [`ccam next --continue`](/features/next) এজেন্টের কথোপকথনগুলো বাদ দেয়, তাই এটি আপনার কথোপকথনই চালিয়ে যেতে থাকে।

## নিরাপত্তা ও বিশেষ ক্ষেত্র

- কোনো এজেন্ট নিজের এজেন্ট চালু করতে পারে না: ccam তাকে `CCAM_AGENT=1` দিয়ে চিহ্নিত করে, আর সেখানে `ccam agent` চলতে অস্বীকার করে।
- `ccam agent` থামালে (Ctrl+C, কোনো সিগন্যাল, বা Claude Code কমান্ডটি থামিয়ে দিলে) এজেন্টও থেমে যায়।
- যে কথোপকথন এজেন্টকে ডেকেছে এজেন্ট সেটি দেখে না, শুধু তার কাজটি দেখে।
- একই ফাইল একসঙ্গে সম্পাদনা করা এজেন্টরা একে অপরের কাজের ওপর লিখে ফেলে। প্রত্যেককে কাজের নিজস্ব অংশ, বা নিজস্ব git worktree দিন।
- যে সেশন এজেন্টদের ডেকেছে সেটি অন্য অ্যাকাউন্টে চলে গেলে ([`auto_switch`](/features/next#auto-switch)), এর চালু করা এজেন্টরাও এর সঙ্গে থেমে যায়। তাদের কথোপকথন থেকে যায়: `--resume <id>` সেগুলো চালিয়ে যায়।
- `agent` একটি কমান্ডের নাম, তাই কোনো নতুন অ্যাকাউন্টের নাম `agent` রাখা যায় না; আগে থেকে থাকা এমন অ্যাকাউন্ট এখনও `ccam run agent` দিয়ে চালু হয়।
